# LumaStudio Mac 0.4.2 (8) 使用与验收

交付日期：2026-11-13。面向 macOS 14 及以上、Apple Silicon（arm64）Mac。本版收束本地摄影工作流；不包含本轮 iPad 交付。

## 直接使用

打开交付文件夹的 `LumaStudio.app`，也可解压 `LumaStudio-macOS.zip` 后打开。应用包含原生渲染、MetalPetal、llama 运行库和 LibRaw 备用解码器；普通修图与导出不需要安装 Python、Homebrew 或 Ollama。GGUF 权重和私人照片不在交付压缩包中，未安装模型时可用本地规则或自己的在线 API。

1. 导入照片或文件夹，在“精修”中调整同一份非破坏性配方。原片不写入；历史 v1 配方自动迁移。
2. 右侧提供调色、局部、人像、滤镜、裁剪、RAW、预设和导出。179 个标量控制另加四通道曲线与局部笔触，支持精确输入、滑块、重置、撤销/重做及 AI 参数锁。RAW 项按实际文件能力启用。
3. “AI 助手”输入要求后，在线模型或本地规划器产生受约束的编辑参数，本机完成渲染。顶部过程图标查看分析、规划、执行、检查和保存记录；来源与回退原因明确展示。结果仍可手动修改。
4. 底部照片条支持星标、旗标、筛选与排序。勾选目标后，可按 13 个分组同步参数，保留目标已锁定值；本次打开期间可撤回整组同步，若目标后来改过则先检查冲突。
5. 批量页选择“统一当前配方”“每张已存设置”或“逐张 AI 调整”。逐张 AI 会先保存每片方案，再导出；重试和恢复复用已存方案。处理过程中可暂停、继续或取消。
6. 黄色“导出”直接保存到当前图库 `Exports`；旁边菜单可指定文件夹。支持 JPEG 8 位、PNG/TIFF 8 或 16 位、长边、DPI、ICC、EXIF 选择与命名，已有文件不会被覆盖。

默认图库位于 `~/Pictures/LumaStudio/Library`。导入菜单可选择其他本地图库位置；切换图库不会自动移动已有文件。菜单“工作区”可切换标准与紧凑布局，最小内容区为 1040 × 680。

## 在线模型与语音

右上角网络图标打开接入设置，填写自己的服务地址、模型 ID 与凭据。DeepSeek 已验证使用 Chat Completions 兼容接口；请求显式关闭思考，避免思考内容耗尽配方返回预算。其他服务仍按所选接口执行，未将兼容接口等同于全部服务均已实连。

凭据可保存于系统钥匙串，或点击“本次会话使用”仅放在内存；退出后会话凭据清除。不同临时签名构建可能无法读取旧钥匙串条目，此时可使用会话方式，应用不会阻塞等待或降低系统访问保护。原有钥匙串条目保留。默认不附带照片预览，在线服务接收文字要求与分析指标；只有主动勾选后才附带小图。

Mac 听写入口和小智 MCP / 本机语音 HTTP 接口已接入代码；小智需自己的接入点。协议测试通过不代表已连上小智官方设备，也不代表真人语音质量已验收。详见 [接入说明](INTEGRATIONS.md)。

## 本次实际验证

- 共享 Swift 套件执行 89 项：零失败，完整运行中 1 项旧图库迁移因样本路径漏传而跳过；该项随后用正确的原始图库样本单独补跑，1 项通过、零跳过。CUBE 缓存损坏后的重新导入、中文否定美颜表达各有收尾针对性补跑。
- 语音 stdio 适配器 3 项通过；既有训练环境中的流水线回归 6 项通过。没有进行新的产品模型训练，没有生成新的训练效果结论。
- 149 个非 RAW、非人像和非输出标量，在依赖功能启用时逐项产生非零像素差。人像与 RAW 有独立真实样片检查；这些是算子生效证据，不是审美评分。
- 8 张独立 CC0 RAW 的 CR2、CR3、NEF、ARW、RAF、ORF、DNG、PEF 已重新解码并导出；另有 Panasonic RW2 和多种普通图像格式验证。Fuji 压缩 RAF 由内置 LibRaw 备用路径处理。
- 最终界面已实际操作：v1 配方文件载入、两张原有配方恢复、滤镜选择与撤销、星标/旗标持久化与筛选、紧凑布局、只同步白平衡且保留曝光、两张整组撤回、按每片已存配方批量导出。Sony 与 Fuji 生成了真实 JPEG，均为全尺寸，2/2 完成、零失败。
- DeepSeek 曾完成 8 张独立 RAW 的 CLI 在线批处理，8/8 成功且无本地回退。另一次 4 张界面批次有 3 张在线、1 张因返回不完整而明确回退本地，4 张均导出。收束时 Canon CR3 的实际在线修图和导出再次通过，来源明确为 DeepSeek；不把回退当作在线成功。
- 用户原来的 G9 与人像配方通过原生文件选择器恢复，G9 曝光 2.669364、人像曝光 0.35；原片不修改。QA 星标和同步临时调整已清理。

原始测试日志、界面截图和结果 JSON 位于工作区 `Artifacts`，同时提供独立的 `LumaStudio-validation.zip`。包内 `MANIFEST.json` 记录最终可执行文件哈希、源码提交、压缩包哈希及解压签名检查。源码包独立于验证素材。

## 明确限制

本包使用本机临时签名，未做 Developer ID 公证；适用于本机与开发验证，尚不是正式商店发行版。没有测量或承诺对像素蛋糕的 99% 复现，也没有可审计的 Jarvis 功能百分比。

实际美颜为皮肤蒙版内的高低频平滑、纹理保护、细节与肤色控制。语义祛痘、眼齿美化、五官/身体重塑、头发/衣服/天空专用分割、生成式填补、训练好的商业精修网络均未交付。参考色彩采用本机统计方法。
