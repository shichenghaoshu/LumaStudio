# LumaStudio Mac 0.5.3 (19)

新增轻柔／标准／更强预设力度、一键强效和美颜专用同步入口；修复预设覆盖锁定美颜参数的问题。高强度磨皮加入结构保护，皮肤蒙版使用连续概率，跨 GPU 处理限制在人脸区域及滤波边界；独立祛瑕和细节恢复减少多余磨皮计算。

算法阶段本机 Release 132 项检查全部通过，无跳过；12 张不同公开照片、48 个光照案例、252 组预设／力度检查，以及 12 张原尺寸批量导出通过。build 19 的共享算法与测试保持该版本输入，Mac Release 重新编译及严格递归签名验证通过。完整方法、性能尾延迟和未验收范围见[美颜优化](BEAUTY_OPTIMIZATION.md)。

新增[快捷修图](WORKFLOW_EFFICIENCY.md)：常驻强效美颜（⇧⌘B）、上一张／下一张（⌥←／⌥→）、原图对照（⌘\\）与导出（⌘E）。目录操作支持粘贴完整路径、拖入文件夹，也保留系统浏览入口。导出按钮按当前设置直接生成新文件，原片不变。

最终原生验收在四张公开测试照片的独立图库执行，确认三档力度、一键强效、参数锁、单步撤销／重做、切图与重启保存、只同步美颜及整组撤回、通用同步恢复推荐、重复导入去重，以及 2615×3269 JPEG 实际导出。目标合影的裁剪、旋转、局部蒙版和锁保持。build 19 修复目标正打开时撤回同步被旧预览配方覆盖的问题。验收后恢复原图库，十一张原片、编辑与标记哈希和本次基线相同。

安装包适用于 macOS 14+ Apple Silicon。仅本机临时签名，未经 Developer ID 公证。历史 Mac 0.5.1 归档保留；Windows／Android 保持 0.5.0，本轮未重新构建或实机验收。

更强预设有意产生明显美白和纹理弱化，可能显得夸张；没有新的商业精修模型训练。热渲染中位数下降，但强效模式仍观察到约 99–113ms 的偶发长帧，不能据此宣称实际界面完全流畅。系统文件选择服务的自动化确认和 Desktop 目录的系统文件打开等待未验收解决；可使用已经实际通过的 Pictures 图库与直接路径方式。本轮没有新的在线模型调用、真人语音或相机实机验收。发布资产、源码提交、CI 和二进制对应关系以随包 MANIFEST.json 为准。
