# LumaStudio Mac 0.5.3 (17) 美颜优化候选

新增轻柔／标准／更强预设力度、一键强效和美颜专用同步入口；修复预设覆盖锁定美颜参数的问题。高强度磨皮加入结构保护，皮肤蒙版使用连续概率，跨 GPU 处理限制在人脸区域及滤波边界；独立祛瑕和细节恢复减少多余磨皮计算。

本机 Release 132 项检查全部通过，无跳过；12 张不同公开照片、48 个光照案例、252 组预设／力度检查，以及 12 张原尺寸批量导出通过。Mac Release 编译及严格递归签名验证通过。完整方法、性能尾延迟和未验收范围见[美颜优化](BEAUTY_OPTIMIZATION.md)。

**Mac 锁屏使新增原生界面操作尚未验收，当前仅为本地候选。**原公开稳定 Mac 0.5.1 保留，Windows／Android 保持 0.5.0；本轮不替换正式包或创建正式版本标签。候选仅本机临时签名，未经 Developer ID 公证。

更强预设有意产生明显美白和纹理弱化，可能显得夸张；没有新的商业精修模型训练。热渲染中位数下降，但强效模式仍观察到约 99–113ms 的偶发长帧，不能据此宣称实际界面完全流畅。解锁后应先在独立图库完成预设、锁、撤销、同步默认分组、保存重启和全尺寸导出验收。
