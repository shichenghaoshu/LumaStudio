# Mac 0.5.1：选片色标

本轮在已发布的 0.5.0 基础上补齐 Mac 颜色标签。Windows / Android 保留 0.5.0 的功能范围。

交互参考来自像素蛋糕的[公开工作区说明](https://wiki.pixcakeai.com/guide/9379.html)：用星标、旗标、色标组织照片，并按标记筛选。LumaStudio 使用自己的 SwiftUI 实现。

## 使用

- 在照片条的“标记”、缩略图右键菜单或批量页“标记所选”中设置红、黄、绿、蓝、紫五种色标；“清除色标”只移除颜色标签。
- 缩略图标签同时显示颜色名称与颜色图标，无障碍标签会读出色标名称。
- “筛选”中新增色标条件，可选择某种颜色、“无色标”或“全部色标”。其中“无色标”只显示未标颜色的照片，“全部色标”不限制颜色。
- 色标可以和文件名、星级、旗标及 RAW 条件组合使用；精修照片条与批量页共用筛选。
- 更改筛选或标记后，隐藏照片从批量选择中移除。导出入口仍再次限制到可见照片。

## 数据与验证

色标存入原有 `reviewData` JSON，未增加 SwiftData 表字段。旧版本只包含 `rating` 和 `flag` 的 JSON 仍可读取，缺少的色标按“无色标”解释。修改颜色保留星级/旗标，修改星级/旗标也保留颜色；不会改写图像原片或编辑配方。批量写入先验证所有目标，目标失效时整组不提交。

针对性测试覆盖旧 JSON 兼容、色标序列化、组合筛选、无色标与全部色标的区分、图库重开后保留、单字段更新、批量目标失效时无部分写入，以及原片/配方保持一致。完整结果见 [0.5.1 交付说明](RELEASE_0.5.1.md) 与公开验证包。

已在独立公开样片图库完成单张/批量标色、组合筛选、清色保留星级与旗标、重启恢复和紧凑布局验收。修正了色标与旗标、星级同显时的文字换行，以及批量页菜单拉伸。测试结束后恢复原图库，核对原有 11 条配方、选片标记和原片哈希均未变化。
