# LumaStudio Mac 0.5.2 (16) 验收候选

本次修正了实际图像处理中失效或方向不符的控制，并补齐可复现的图像效果合同。**原生界面最后验收因Mac锁屏仍待继续，当前不作为已通过最终验收的正式发布。**公开稳定版仍为0.5.1，Windows／Android保持0.5.0。

- 正向高光现在实际提升高光区域。
- 关闭磨皮不再关闭独立美白、肤色、瘦脸与大眼。
- 颜色分级“平衡”正值偏向高光、负值偏向阴影。
- 传统美颜备用路径的独立祛瑕及细节恢复已生效。
- RAW面板说明缩小预览中的锐度可见性；原尺寸输出实际验证。
- 导出软件字段使用LumaStudio标识，避免残留早期版本号。

Release构建120项检查全部通过，无跳过。184标量中172项通过预期效果／文件检查，11项RAW控制按文件支持，1项RAW局部影调在本轮全部样本中不支持并保持禁用。5张独立人像、30滤镜、9相机RAW的原尺寸批量、30导出组合、8EXIF方向和真实DeepSeek规划／渲染／导出均有实际执行证据。详情见[算法验收](ALGORITHM_ACCEPTANCE.md)。

强效美颜会出现明显蜡感与纹理损失；这不等于专业美学质量保证。默认皮肤分割为Vision关键点与传统方法，没有新训练的商业级修图模型。真人听写、小智官方设备、真实相机控制、跨设备传输及Windows／Android本轮真机验收未完成。Mac包使用本地临时签名，未经Developer ID公证。
