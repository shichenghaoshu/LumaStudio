# Mac 0.4.2：选片与参数同步

本轮补齐选片、同步参数、保留各片独立调整后导出的流程。沿用 LumaStudio 的原生 SwiftUI 工作台和 v2 配方，不引入第三方产品代码或资源。

交互参考：像素蛋糕公开的[批量应用效果说明](https://www.pixcakeai.com/guide/64507)和[工作区说明](https://wiki.pixcakeai.com/guide/9379.html)。采用其选择同步功能、星标和旗标筛选的工作流；页面视觉与各自图像算法不作一致率声明。

## 使用

1. 在精修页面调整一张照片。照片条的圆圈用于选择其他照片，点击缩略图本身进入单张编辑。
2. 点击“同步…”或右侧“同步所选参数…”。在弹窗中选择目标照片及参数分组，也可“全选可见”。当前照片不作为目标。
3. 确认“同步到 N 张”。参数写入目标照片的图库记录；不会在此步骤导出文件。
4. 进入批量页，选择“每张已存设置”，使用各片独立的参数、裁剪、局部区域和输出设置导出。该模式在同步成功后自动选中。

可同步 13 个分组：曝光与影调、白平衡、颜色/HSL/校准、RGB 曲线、三向分级、滤镜/参考色彩、人像美化、锐化/降噪、质感/效果、RAW 解码、裁剪/几何、蒙版/画笔和导出设置。默认选中常用调色、细节与效果分组。构图、蒙版、人像、RAW 和输出设置需单独选择。复制局部画笔时沿用归一化坐标，不自动追踪另一个主体。

目标照片的锁定参数和锁定列表始终保留，来源照片的锁不会覆盖它们。RAW 解码设置只复制到 RAW 目标，仍由各机型解码器决定可用项。

## 选片

- 支持 0–5 星以及未标记、入选、淘汰三种旗标，标记保存在本机图库中。
- 精修照片条的“标记”用于当前照片；批量页的“标记所选”用于已选照片；每张缩略图也有单独入口。
- 按文件名、仅 RAW、最低星标、旗标组合筛选，可按导入时间、文件名或星标排序。
- 精修与批量共用筛选条件。筛选或标记改变后，自动移除隐藏照片的批量选择，导出时再次限定到当前可见照片。
- 淘汰是可撤销的标记，不删除照片。默认仍显示所有旗标。

## 撤回及持久化

一次同步在图库中统一提交。目标缺失、配方无效或写入失败时不留下部分同步结果。可在本次打开期间通过预设面板或批量页“撤回上次同步”。撤回前核对所有目标是否仍等于同步后的版本；若任一目标已有后续编辑，则整组停止撤回。星标变化不阻止配方撤回。

星标/旗标使用新增的可空 `reviewData` 字段，与照片原片和编辑配方分开存储。使用改动前生成的真实 SwiftData 图库副本测试过升级后读取和写入，原照片 ID 与配方曝光值保持一致。测试只访问临时图库，不修改用户现有图库。

“每张已存设置”把每张配方写入批量队列快照，重试和恢复均使用同一配方。每张照片分别解析其引用的本地色彩档案，没有引用的照片不会继承另一张照片的档案。
