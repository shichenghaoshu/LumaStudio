# 0.5.3 美颜优化与验证

本轮承接“优化算法、UI、点击效率、更多样图、美颜效果更明显”的要求。最终 Mac 为 0.5.3 (19)；Windows／Android 保持 0.5.0。算法与样图的完整本机检查来自 build 17，之后的 build 18／19 增加快捷操作、路径输入并修正同步撤回刷新，没有更改共享算法与测试源码；最终版另完成原生点击、保存重启和导出验收。

## 使用流程

在人像面板先选择“轻柔／标准／更强”，再点击自然、精修、瓷白、高强度或塑形预设。力度只影响下一次点击的预设；手动调整后不会由面板状态再次覆盖。原来的标准预设参数保持兼容。

“一键强效”直接应用更强的高强度预设，增加磨皮、美白、肤色均匀和亮度，可用一次撤销恢复。塑形预设另包含瘦脸与大眼，其余预设不自动开启塑形。预设保留粒度参数锁和整组美颜锁，原片、调色、裁剪、局部蒙版、参考图与导出设置不变。

“同步美颜…”打开已有同步窗口，默认只勾选人像美化，继续明确选择目标照片并确认。一般同步入口仍默认原来的推荐分组，不会因为之前使用了美颜入口而沿用它。每个目标继续保留自身锁、构图、蒙版和其他未选分组；可以撤回整次同步。该入口参考像素蛋糕公开的[分组批量同步流程](https://wiki.pixcakeai.com/guide/9591.html)，没有使用其私有代码、模型或素材。

## 算法修改

- 强磨皮用局部方差区分平坦皮肤与结构边缘，结合低频平滑和乘法细节重建，减少鼻翼、暗纹被整片高斯混合抹平的问题。
- 肤色采样改为小区域中位数，亮度／肤色／颈部概率连续过渡，引导滤波后重新限制几何和五官保护区域，保留浮点蒙版。
- 不再随强效程度额外放大皮肤蒙版权重。眼眉嘴保护和无人脸时跳过处理继续保留。
- 仅在实际需要平滑时跨入 MetalPetal；独立祛瑕／细节恢复使用对应频率处理。跨 GPU 上下文只传输包含皮肤的区域及滤波边界，半径仍按整张照片缩放，随后恢复原位置。
- 预设力度展开为已有 v2 标量，不增加配方字段，也不让临时界面状态参与导出。更强属于有意明显的美颜效果，可能损失纹理。

## 验证方法与证据

原 0.5.2 已知真值测试与同机性能基线保留在 `Artifacts/BeautyOptimization/Baseline`。最终本轮证据位于 `Artifacts/BeautyOptimization/Final-2026-11-15`，早期失败／迭代证据保留，没有覆盖为成功结果。

质量合同使用已知干净皮肤色块、可复现噪声、阶跃边缘和细窄暗纹，检查噪声误差及结构误差。肤色、半径、纹理、五官和局部性合同检查方向和区域，不只要求像素发生变化。性能用同一公开人像、同一 M2 Pro、Release、两次预热后七次强制渲染，单独记录分析时间；不含 UI、解码和编码，不代表界面帧率。

扩展样图为 12 张不同公开照片：已有 5 张加本轮新增 7 张 NASA 图片，含单人、6 人合影、4 人不同朝向合影及已有 7 人合影。每张原片运行 5 预设 × 3 力度，另外生成欠曝、明亮、偏暖三个派生案例，各检查两档强效；共 48 个图像案例、252 组预设／力度检查。派生案例不算新增独立样图。另对 12 张照片检查区域处理与整图处理的一致性，并实际经批量处理器输出原尺寸 JPEG、核对原片 SHA256。图片用于本地 QA，没有上传到在线模型或打入应用。

新增来源、下载链接和哈希记录在 `work/beauty-optimization/expanded-sources.json`，遵循 [NASA 图片使用指南](https://www.nasa.gov/nasa-brand-center/images-and-media/)。使用公开照片不表示图中人物或 NASA 认可美颜效果。该小样本不是人群覆盖、专业审美或所有拍摄条件的质量保证。

本轮没有重新训练模型，没有把旧 DeepSeek 实跑记录当作新的服务调用。真实麦克风、相机、跨设备通信以及 Windows／Android 不属于本轮实机验收。

### 本机已完成的结果

最终 Release 回归 132 项，0 失败、0 跳过，101.269 秒；另 3 项语音 stdio 协议测试通过。Mac Release 编译及严格递归签名验证通过。12 张原尺寸批量导出全部成功，原片哈希保持；12 张 × 4 种光照的人脸检出数保持一致，区域处理与整图处理的最大通道差均为 1/255。12 张原图的“更强高强度”在皮肤区域的平均绝对像素改变量均大于“标准高强度”，不能据此推导审美得分。

在同一合成真值中，结构边缘 RMSE 从 14.04 降到 4.31，细窄暗纹从 18.91 降到 10.42；平坦区已知噪声误差从输入 3.83 降到输出 0.63。旧版平坦区输出为 0.53，新版以少量平滑损失换取结构保留，不能称为所有指标同时改善。

同机 1600px 热渲染中位数：独立祛瑕 20.22→5.42ms、自然美颜 19.57→8.38ms、标准高强度 20.04→12.90ms。完整测试中的强效 P95 为 113.23ms；在构建结束后的 3 次隔离复核中，中位数为 11.95／13.04／10.72ms，P95 为 12.30／99.24／11.91ms。偶发长帧仍可复现，后续须继续定位；这些数据不证明界面卡顿已经解决。

## 最终原生验收

Mac 解锁后在独立 Pictures 测试图库实际完成三档力度、一键强效、单步撤销／重做、锁定美白、跨照片切换、正常退出重启和全尺寸导出。只同步美颜保留目标的 1:1 裁剪、3° 旋转、局部人脸蒙版 +0.2EV 和 20% 美白锁；在目标正打开时撤回后四张配方逐项恢复。通用入口恢复八组推荐参数。原图库十一张原片、配方、标记与本次基线逐项哈希相同。

验收中发现并修复了“撤回同步成功后，刷新当前目标又保存旧配方”的真实问题；失败证据保留在 build 18 的记录中，build 19 重新执行同一路径通过。具体点击路径、二进制哈希与剩余系统浏览器限制见[快捷修图](WORKFLOW_EFFICIENCY.md)。这些原生操作证据不扩大为全部专业人像审美、真人语音或相机实机验收。
