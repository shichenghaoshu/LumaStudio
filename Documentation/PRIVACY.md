# 隐私说明

LumaStudio 不要求注册，没有广告、统计或追踪 SDK。应用内没有云端 AI、互联网照片中转、远程照片数据库或自动 iCloud 同步。Core Image、Vision 和可选 Core ML 全部在设备上执行。

照片由用户导入并复制到用户选定的本地图库；默认 Mac `~/Pictures/LumaStudio/Library`，iPad 为应用 Documents/LumaStudio/Library。SwiftData 显式禁用 CloudKit。选择第三方文件提供程序或 iCloud 文件夹时，由用户选择的系统文件服务负责该位置，本应用不会自动作出这个选择。

原始文件不修改。图库含原片副本、缩略图、哈希和编辑配方；批量任务日志含本地文件路径、参数、进度和错误原因。日志不写照片像素、脸部关键点、配对密钥或完整照片内容。系统 Vision 分析结果只短暂驻留内存，未建立人脸身份库。

只有在用户开启 Host/发现、配对并发送时才使用局域网。传输使用 Bonjour、TLS 1.2 PSK / AES-GCM，完成后进行 SHA256 校验。未知密钥无法建立连接。配对链接和二维码包含 256-bit 密钥，等同密码，应只给自己的设备；本机使用 Keychain 保存。初版撤销功能轮换 Host 密钥并使所有已配对设备失效，暂不支持逐台撤销。

Host 只宣告已验证的原生快门能力；没有相机验证就不能通过 iPad 触发拍摄。USB 官方 Tether 和普通设备局域网是两条独立连接。

用户可在 Finder/文件 App 中备份或删除自行选择的图库和导出文件。本应用不主动删除原片。Keychain 配对可通过“撤销全部配对”使旧密钥失效。

## Mac Edge AI 本地记录

自然语言要求、每轮配方、图像指标和每轮预览保存在当前图库的 `AgentHistory`；用户主动点击“记住这个风格”后，参数偏好保存在 `LocalMemory/preferences.json`，可以在模型与偏好面板清除。它们不自动成为训练数据，也不会上传。模型安装清单与权重在本机 Application Support 的 ModelPackages 中，按内容哈希验证。

独立 `Training` 工具只接受明确授权且原图哈希匹配的数据。用户若另行配置并运行 GPU 教师服务，只有这套研发工具会向明确指定的训练环境传输经过预处理的已授权照片；最终 Mac 应用没有训练服务器或云推理请求。默认规则数据演示完全在本机执行。
