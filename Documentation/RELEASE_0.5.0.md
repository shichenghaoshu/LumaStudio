# LumaStudio 0.5.0 · 性能与三平台发布

本版面向 macOS、Windows 与 Android。Mac 保留完整专业工作台；Windows / Android 首次提供可离线导入、调整、保存和导出的编辑器。三端的功能范围与配方格式有所不同。

## 下载与安装

下载入口：[GitHub Release v0.5.0](https://github.com/shichenghaoshu/LumaStudio/releases/tag/v0.5.0)。核对同页 `SHA256SUMS.txt` 后使用对应文件。

- **Mac**：`LumaStudio-0.5.0-macOS-AppleSilicon.zip`，适用于 macOS 14+、Apple Silicon。解压后使用 `LumaStudio.app`。此包使用本机临时签名，未做 Developer ID 公证；macOS 可能提示无法验证开发者。原有图库仍在用户“图片/LumaStudio/Library”中，更新应用不会替换图库。
- **Windows**：`LumaStudio-0.5.0-Windows-x64.zip`，适用于 Windows 10/11 x64。完整解压后运行 `lumastudio.exe`；保留旁边的 DLL 与 data 文件夹。已随包提供官方 Visual C++ 运行库，当前未做商业代码签名，系统可能显示来源提示。
- **Android**：`LumaStudio-0.5.0-Android.apk`，适用于 Android 7.0+ 的 ARM64 / x86_64 设备。使用独立发布证书签名，后续更新沿用相同证书。旧测试版若使用另一证书，须先导出私有图库再卸载旧测试版；卸载会移除应用私有照片副本和配方。

源码与验证记录分别位于 Source / Validation 压缩包；`MANIFEST.json` 记录构建来源、资产校验值和验证范围。本次没有 iPad、Intel Mac 或 Windows ARM 原生包。

## 这次改进了什么

Mac 改用细粒度状态观察，减少改动单个参数时的界面刷新；RAW 能力探测离开界面线程；过期预览可提前取消。预览任务合并为最新状态，持续调参时可以产生中间画面；受限缓存复用 HSL / 曲线色彩变换。切换照片独立保存离开的配方，正常退出前等待当前配方写入完成。

Mac 专业滑块采用连续轨道并在写入时按参数步长取整，保留精确输入与无障碍微调，避免 AppKit 为细步长生成大量刻度而阻塞窗口布局。

在本地 M2 Pro 的 Release 图像引擎基准中，热预览影调中位数从 **32.8ms 降到 30.3ms**，影调加 HSL / 曲线从 **34.6ms 降到 29.1ms**；相应 P95 从 39.1 / 36.3ms 降到 32.9 / 31.9ms。两组导出 PNG 的 SHA256 与优化前一致。这是固定样片的引擎耗时，不代表端到端界面帧率、移动设备速度或所有 RAW 的性能。

Windows / Android 的解码、预览和完整尺寸导出放在工作进程；同时最多执行一项预览，后续请求由最新状态替换。C++ 把影调、HSL 与滤镜编译成一次缓存的色彩变换。完整尺寸导出使用独立工作进程、按队列串行执行。

## 可以做什么

- **Mac 专业版**：184 个标量控制、曲线、局部蒙版、RAW 调整、30 款原创滤镜、真实 GPU 美颜、非破坏历史、选片同步、三种批量方式、16 位 / ICC 输出、在线模型与本地推理接口。相机、小智和模型训练的具体限制延续相关模块文档。
- **更强的 Mac 美颜**：在“人像”面板选择“自然 / 精修 / 瓷白 / 高强度 / 塑形”。新增强效磨皮、瓷白美白、红润肤色、瘦脸和大眼五项；纹理保留可调至 0。瘦脸、大眼由 Vision 关键点与局部坐标变形实际执行，眼口保护使用柔和渐变。高强度、塑形允许明显的塑料感与夸张外观，可撤销或继续手动调节；未检测到人脸时不执行 Mac 美颜。
- **Windows / Android**：48 个数值控制（24 个基础参数与 8 色 HSL 的 24 个值）、30 款原创 CUBE 滤镜、撤销/重做、逐张配方保存、旋转/翻转/中心裁切、统一/已存/自动影调批量、JPEG / PNG 完整尺寸或指定长边导出。肤色面板有“自然 / 精修 / 瓷白 / 高强度”四种预设及八项肤色参数。可用内置 CC0 风景示例体验，也可导入自己的照片。
- **格式**：Portable 支持 JPEG、PNG、TIFF、WebP、BMP、GIF 首帧、PSD 合成图等，以及 LibRaw 0.22.3 支持的相机 RAW。已用 Canon CR2/CR3、Nikon NEF、Sony ARW、Fuji RAF、Olympus ORF、Leica DNG、Pentax PEF 独立样片验证图像闭环；不能据此保证所有机型和压缩变体。HEIC 请使用 Mac。
- **在线模型**：Portable 在“接入与导出设置”填写兼容 Chat Completions 的 HTTPS 地址、模型和密钥。只发送文字与参数，默认不上传照片；密钥仅保留在会话内存。严格验证模型建议，失败或取消保留已有编辑。Mac 可使用钥匙串保存接入信息。

## 明确的限制

Windows / Android 没有 Mac 的完整 184 项控制、局部蒙版、四通道曲线、人脸几何塑形、16 位 / ICC、相机联机、本地 Qwen 和语音接口。Portable v1 配方与 Mac EditRecipe v2 暂不互通，未知配方会明确拒绝。

Portable 肤色柔化是颜色范围算法，可能影响相近颜色；没有人脸专用分割、瘦脸或语义祛痘模型。Mac 使用 MetalPetal 平滑、Vision / 传统蒙版与局部几何变形，没有捆绑商业精修网络。LumaStudio 专业模型训练尚未执行。两端均未提供牙齿分割美白、身体重塑或生成式内容填补。

Portable 单文件最大 512MB、最大 80MP；实际可处理大小受设备内存影响。移动端建议分批处理大 RAW。输出为 8 位 sRGB，并移除 EXIF / GPS。原文件保留，已有导出文件不会在未明确选择新位置的情况下被应用直接覆盖。

## 验证说明

Mac 的共享测试与真实 RAW / 人像 / 历史图库补验分别记录；原生 Release 实际检查包含图像与直方图更新、切换保存、立即退出后恢复和 JPEG 导出，验收结束后逐项核对原有图库配方与标记未改变。连续鼠标拖动的自动化受到本机界面驱动限制，没有声称测得 GUI FPS。

增强美颜另以 NASA 公开人像检查五种风格的真实像素、未蒙版背景保护与独立几何变形，并人工查看输出；这是一张公开测试照片的执行证据，不是多肤色、多人脸、姿态或专业审美的全面验收。

Windows 在 Windows 2022 runner 上运行实际编辑器界面测试，再构建 Release；编译后的程序从包内加载 DLL，执行独立图库的真实像素、导出、撤销、批量与重启检查，并处理带中文文件名的 Canon / Fuji RAW。最终结果以该版 `MANIFEST.json` 关联的成功 CI 记录为准。

Android 在 Android 15 / API 35 ARM64 模拟器执行真实界面测试，并检查发布签名、非调试标志、ABI 与 16KB 对齐。实体 Android 手机和用户的 Windows 电脑未做人工验收。本轮没有再次使用真实密钥调用 Portable 在线服务，网络错误、取消与不上传图片通过模拟 HTTP 测试验证；Mac 0.4.2 的真实在线服务记录属于历史证据。

第三方许可随应用与源码保留，详见客户端“开源许可”及对应目录。分发包不包含 API 密钥、个人图库、商业计划书、逆向私有资料或模型权重。
