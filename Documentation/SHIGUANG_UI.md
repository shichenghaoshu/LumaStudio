# 拾光 0.7.0（29）Mac 界面

产品名由 LumaStudio 改为拾光。使用用户提供的金色商标原图，原始 PNG 的 SHA-256 为 e9c64ab32fd1fdd9518ad32ad47cc91aa5a111f4f7c214b5989e5eacc0281f56；未重绘商标，也未添加注册商标标记。用于工作台、助手、侧栏、应用图标与创作中心。应用内部标识、配对协议、图库路径、钥匙串服务和已有数据沿用原版本。

工作台使用中性炭黑背景、香槟金强调色，照片继续作为主要区域。顶部切换精修／AI 助手／批量；导出为主要动作，参数面板可直接显隐。常用按钮的触发区至少32点，画布工具至少44点宽；参数输入提供聚焦边框，组锁定与重置按钮加大。

交互：悬停高亮、约120ms按下／释放、明确选中状态；系统减少动态效果或设置关闭动画时停止缩放与面板过渡。触控板反馈使用 AppKit 原生触感，只在支持的设备生效；鼠标提供视觉反馈。物理触感强度与实际主观感受未由自动化验证。菜单“拾光 → 设置”可关闭触感和轻量动画。

快捷键：⌘1 精修，⌘2 AI 助手，⌘3 批量；⌥⌘I 显示／隐藏参数，⇧⌘C 前后对比，⌘\ 查看原图，⌘↩ 发送助手要求，⌘E 导出。关闭在线 API 时仍可以使用本地模型／规则。

原生界面、紧凑窗口、快捷键和图片数据保护的实际验收结果以交付目录的验证回执为准。界面改动不代表本次重新训练或提升了修图模型。
