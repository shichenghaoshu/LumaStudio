# LumaStudio Mac 0.5.1 (15)

本次更新范围为 Apple 芯片 Mac，最低 macOS 14。Windows / Android 继续使用已发布的 0.5.0，本次没有对应的新安装包。

## 编辑响应

- 拖动滑块、曲线或色轮，以及连续编辑数值时，使用长边 960 像素的交互预览；结束操作后自动重新生成长边 1600 像素的精细预览。导出仍从原片按输出设置重新处理。
- 同一张照片的两种预览复用已解码图像，分别缓存对应的人脸分析；缓存有数量和内存上限。
- RAW 参数使用稳定的缓存键。文件大小、修改时间和文件标识发生变化时缓存失效，避免同一路径换图后继续显示旧照片。
- “照片与处理信息”可查看当前预览尺寸、交互/精细状态、真实后端和本次渲染耗时。

交互预览处理的像素较少，细节用于实时反馈；最终精细预览和导出使用既有处理流程。单张样片的引擎耗时不等于整套界面的帧率，也不代表其他设备或所有照片。

## 选片

照片条“标记”、缩略图右键菜单和批量页“标记所选”新增红、黄、绿、蓝、紫五种色标。可单独清除颜色，保留星级与旗标；色标与名称、RAW、星级和旗标组合筛选。选择“无色标”仅显示未标颜色的照片，“全部色标”不限制颜色。更改筛选会移除已隐藏的批量选择。

原生文件夹选择在菜单关闭后开启完整模态会话，已通过测试图库与原图库往返切换。紧凑布局下的颜色名称保持单行，批量页筛选和标记菜单按内容宽度排列。

## 强效美颜

保留 0.5.0 的自然、精修、瓷白、高强度和塑形五档预设，以及纹理降至 0、强效磨皮、美白、红润、瘦脸和大眼。此次优化这些功能的交互预览，没有宣称新增训练过的商业人像模型。尚不提供完整五官重塑、身体重塑或生成式补画。

## 验证状态

本机 98 项共享模块回归零失败，1 项可选本地模型权重未启用；另有 7 项针对性预览/RAW 回归零失败。覆盖真实 RW2 的缩略图、交互、精细和全尺寸显影、强美颜的精细输出恢复、画笔位置、裁剪、源文件替换和非覆盖导出。Release 构建、严格签名校验与 3 项语音接口协议测试通过。

同一张公开 NASA 人像、同一 M2 Pro、Release 构建，每组 25 次（首帧单列，其余 24 次取热中位数）：

| 处理 | 旧精细预览 | 新精细预览 | 新交互预览 |
| --- | ---: | ---: | ---: |
| 影调 | 30.9 ms | 7.3 ms | 3.3 ms |
| 高强度磨皮 | 48.6 ms | 23.4 ms | 9.8 ms |
| 高强度磨皮与塑形 | 48.9 ms | 23.8 ms | 9.7 ms |

精细预览均为 1280×1600，交互预览为 768×960。三组新精细输出及交互结束后的精细输出，均与对应的旧精细输出逐像素相同。交互预览本身分辨率较低，不能把其耗时当作精细画质的处理耗时。

原生界面已在 0.5.1 (15) 完成验收：单张/批量标色、清色保留星级与旗标、红色+五星+入选组合筛选、重启恢复、标准/紧凑布局、连续数值输入期间交互预览、结束后精细预览恢复，以及实际 2615×3269 JPEG 导出。原片哈希不变；测试结束后恢复原图库，原有 11 条配方和选片标记及 11 张原片哈希核对一致。截图均来自独立图库中的公开 NASA 样片（同一源图的副本），不代表多场景人像主观质量评审。

实际界面中观察到的一次交互/精细渲染为 225/134ms，包含当时运行状态；与上表热引擎测试的条件不同，二者不能相互替代。云端共享测试、语音协议与 Mac Release 构建结果随对应提交显示在 [Actions](https://github.com/shichenghaoshu/LumaStudio/actions/workflows/mac.yml)，正式包附匹配源码提交的成功收据。

Mac 安装包采用本机临时签名，未做 Apple 公证。没有新增在线 API 调用、G9 实机或 Windows/Android 的新验收，也没有执行专用模型训练。
