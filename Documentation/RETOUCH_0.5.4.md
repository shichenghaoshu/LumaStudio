# 0.5.4 (21) Mac AI 精修候选

本轮针对强效美颜的泛白、蜡感和弱祛瑕，加入真正的本地预训练美肤模块。当前是可供检查的候选版；Mac 再次锁屏，新增界面的实际操作验收仍待完成，已发布 0.5.3 (19) 保留。

## 新的修图方式

点击常驻工具栏的 **AI 精修**（⇧⌘B），或进入人像面板点 **一键 AI 精修**。提供轻柔、标准、更强三档，分别展开为普通 EditRecipe v2 参数：

| 力度 | AI 局部祛瑕 | AI 光影均肤 |
| --- | ---: | ---: |
| 轻柔 | 60% | 55% |
| 标准 | 90% | 85% |
| 更强 | 100% | 100% |

AI 精修预设不自动增加高斯磨皮、美白、提亮或塑形。瓷白、高强度、塑形及所有原有手动控制仍可单独使用；原“精修”传统预设改名为“柔肤”，其数值保持。

新的两项控制支持参数锁、单步撤销、保存和仅美颜同步。旧配方缺少新字段时默认 0，不自动改变用户已存照片。AI 修复先于全局曝光和调色；拖动曝光及精修力度复用原片预测，不随每帧曝光重新执行网络。结果缓存有数量和内存上限，并可随工作台释放。

## 实际接入的模块

使用 [ModelScope 官方高清人像美肤模型](https://www.modelscope.cn/models/iic/cv_unet_skin-retouching/summary)，官方标注 Apache License 2.0。三个 Core ML FP16 模块总计约 135 MB，随完整包离线提供：局部瑕疵检测、局部修复、自适应混合层。无新训练；没有调用在线服务或上传照片。源代码出处、完整许可、适配说明及 SHA-256 清单一起保留。

修复差值和混合层映射回原尺寸像素，并受皮肤、五官及人脸区域约束。传统磨皮、肤色调整和塑形继续作为独立步骤。模型转换与精度核对方法见 [转换工具](../Training/conversion/retouching/README.md)。

本机未安装 Photoshop 或 Retouch4me。本轮没有运行或打包商业 PS 插件。Adobe UXP 运行于相应 Adobe 宿主；Retouch4me 等插件另需安装和授权。此候选实际使用上述开放许可模型及原生图像管线。

## 效果与性能范围

公开痘印样图中，局部痘印和肤色不匀可见减轻，并比旧强效预设保留更多原有肤色和侧光。这是本批样图的直接观察，不代表完成全人群或专业修图师评审。

首次模型编译/载入及单脸处理在本机观察约 3.2 秒；之后新脸约 0.16–0.20 秒推理，参数变化可命中缓存。旧记录单人完整重渲染含 PNG 编码约 23–24 ms，双人约 67–68 ms，仅为样本记录，不是 UI 帧率保证；并行编译期间的性能矩阵不用于性能结论。

小于 100 像素的人脸跳过专用模型。合影的缩小交互预览可能跳过部分小脸，原尺寸导出会按原尺寸重新判断。模型可能将痣、雀斑也视为瑕疵；降低局部祛瑕即可保留更多特征。此适配使用固定 576px 局部修复，与上游原尺寸分块修复不同，细小瑕疵可能遗漏。人体皮肤全身精修、商业 PS 插件宿主及本轮 Windows/Android 版本没有新增验收。
