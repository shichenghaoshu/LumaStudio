# Mac 0.5.3 (18) 快捷修图

精修工作区右上角始终显示“强效美颜”。从调色、滤镜或裁剪等面板点击一次，即应用更强的高强度预设并打开人像参数。保留参数锁，可单步撤销。人像面板的预设力度同步显示“更强”；切换面板不会重置这个下一次预设力度。手动调参仍直接写入当前照片的 v2 配方。

画布下方提供上一张、下一张；沿当前筛选与排序移动，到首尾停止。渲染或其他工作尚未结束时暂时禁用，避免误切换。每张照片继续读取自己的编辑记录。

常用快捷键：

- `⇧⌘B`：一键强效美颜。
- `⌥←` / `⌥→`：上一张 / 下一张。
- `⌘\`：原图 / 效果切换。
- `⌘E`：按当前设置导出到当前图库的 Exports 文件夹。
- `⌘Z` / `⇧⌘Z`：撤销 / 重做。

导入文件夹、切换图库、选择导出目录等操作支持粘贴完整路径或拖入文件夹，也保留系统“浏览…”按钮。导入照片和载入模型要求现有目录；创建图库与导出时可以新建目标文件夹。文件夹导入的初始路径为空，用户明确选择后才开始读取。

本机界面验收使用独立的图片目录图库，已经实际导入三张公开人像与一张 G9 RAW，验证一键更强、一次撤销、20% 美白参数锁、切图保存及 2615×3269 原尺寸 JPEG 导出。源代码和可执行文件的最终收据在本地验收目录中单独绑定；系统文件选择服务的自动操作与桌面目录的系统文件打开等待仍单独记录，不能把路径输入流程的通过当成系统浏览器已经通过。

算法、12 张独立照片与 48 个光照案例的证据见[美颜优化记录](BEAUTY_OPTIMIZATION.md)。界面追加不改变算法参数的定义、相片裁剪、局部蒙版或同步规则。公开稳定版的替换须等最终原生验收与对应构建检查完成。
