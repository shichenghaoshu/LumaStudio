# Mac 0.5.3 (19) 快捷修图

精修工作区右上角始终显示“强效美颜”。从调色、滤镜或裁剪等面板点击一次，即应用更强的高强度预设并打开人像参数。保留参数锁，可单步撤销。人像面板的预设力度同步显示“更强”；切换面板不会重置这个下一次预设力度。手动调参仍直接写入当前照片的 v2 配方。

画布下方提供上一张、下一张；沿当前筛选与排序移动，到首尾停止。渲染或其他工作尚未结束时暂时禁用，避免误切换。每张照片继续读取自己的编辑记录。

常用快捷键：

- `⇧⌘B`：一键强效美颜。
- `⌥←` / `⌥→`：上一张 / 下一张。
- `⌘\`：原图 / 效果切换。
- `⌘E`：按当前设置导出到当前图库的 Exports 文件夹。
- `⌘Z` / `⇧⌘Z`：撤销 / 重做。

导入文件夹、切换图库、选择导出目录等操作支持粘贴完整路径或拖入文件夹，也保留系统“浏览…”按钮。导入照片和载入模型要求现有目录；创建图库与导出时可以新建目标文件夹。文件夹导入的初始路径为空，用户明确选择后才开始读取。

实际操作步数：从调色页应用更强高强度美颜为一次点击；上一张／下一张各一次点击；按既定输出设置导出为一次点击或一个快捷键。美颜同步保留明确选目标和确认，实测为入口、单个目标、执行共三次点击。这里只统计这些具体路径，不将其换算成未经测量的整体效率百分比。

本机界面验收使用独立的 Pictures 目录图库，实际导入三张公开照片与一张 G9 RAW，验证轻柔／标准／更强、一键强效、单步撤销与重做、20% 美白参数锁、切图保存及 2615×3269 原尺寸 JPEG 导出。重复导入仍为四张照片，正常退出重启后四张配方完全保持。

只同步美颜的原生复测：来源为强效人像，目标合影独立设置 1:1 裁剪、3° 旋转、人脸蒙版 +0.2EV 与 20% 美白锁。同步仅改变其余美颜值；裁剪、蒙版、锁和其他照片不变。保持目标正打开时撤回同步，四张照片配方均恢复到同步前。build 19 修复了该刷新过程把旧美颜值重新写回的问题。通用同步重新打开时恢复八组推荐参数，人像／裁剪／局部／输出没有被默认选中。

验收后已通过界面切回原图库；十一张照片的原片、配方和标记逐项哈希与本次基线一致，没有用旧快照覆盖用户编辑。最终可执行文件 SHA256 为 `075a1244dd81fa97eaf72865dda5425dbb2287a8a733b48503525388e7cb598c`，原生收据位于验证包的 `Workflow/Build19/mac-final-ui.json`。系统文件选择服务的自动操作与 Desktop 目录的系统文件打开等待仍单独记录，路径输入通过不代表系统浏览器已经验收通过。

算法、12 张独立照片与 48 个光照案例的证据见[美颜优化记录](BEAUTY_OPTIMIZATION.md)。界面追加不改变算法参数的定义、相片裁剪、局部蒙版或同步规则。发布包附实际源码、二进制与云端检查的对应记录；Windows／Android 本轮没有更改。
