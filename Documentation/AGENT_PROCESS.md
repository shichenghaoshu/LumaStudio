# Agent 处理过程页面 · 2026-11-11

目标：在现有 Mac 应用内展示本地 Agent 的实际处理过程，让用户了解执行步骤、查看照片变化并确认采用的版本。

视觉主张：延续 LumaStudio 的深色照片工作台和暖金强调色，以大幅照片作为视觉中心，两侧用分隔线组织执行记录与参数，避免仪表盘卡片堆叠。

内容组织：顶部为任务状态与返回编辑；左侧为指令和分析／方案／渲染／检查／保存时间线；中间展示原图、各轮实际结果与版本选择；右侧为所选阶段对应的分析、参数、工具与确定性指标；底部为继续描述要求、开始或停止。

交互主张：开始时跟随当前步骤，允许点选阶段查看事实；每轮结束后才显示该轮图片与指标；用户可对比原图并明确采用某一轮。状态更新、照片切换和按钮悬停使用短过渡，遵守减少动态效果。

真实性：使用原生 Agent 执行事件与真实保存的预览，无预设百分比、伪造评分、模拟模型思维或 Jarvis 运行身份。当前模型仍是未经过专业修图训练的通用基础模型。原片不变。

状态：Mac 0.2.2 build 4 Release 已编译。46 项共享模块检查通过，含真实样片和原生 Qwen；三轮修正测试验证事件顺序、图片先于通知保存、最终记录及旧 JSON 兼容，中断测试确认没有虚构已完成步骤。最终界面实际操作验收通过。


## 页面入口与操作

从修图页顶部“处理过程”进入，或在助手面板点击“展开 Agent 处理过程”。原有拍摄／修图／批量导航保留。

左侧点击步骤查看事实，任务运行时也可查看已完成的分析；中央切换效果／原图／对照，点击轮次缩略图查看其实际保存结果；右侧显示选中阶段的分析、参数、执行工具、确定性检查或本地保存说明。输入新要求后开始处理；停止会等待当前操作退出，并保留当前编辑。关闭自动修正仍会执行指标检查。采用某一轮后返回编辑页，可继续调整并确认全分辨率导出。
